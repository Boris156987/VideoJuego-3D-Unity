# Escape del Manicomio

Videojuego 3D de terror y escape hecho con Unity 6 (URP) y C#.

## Objetivo
Recoge 3 llaves repartidas por el manicomio, evita a los zombis y escapa por la salida.

## Descargar el Build
Ve a la sección **Releases** de este repositorio, descarga `Escape_del_Manicomio.zip`, descomprímelo y abre `Escape del Manicomio.exe`.

## Controles
- WASD: moverse
- Mouse: mirar
- Shift: correr
- Espacio: saltar

## Sistemas implementados
- Controlador en primera persona
- IA del zombi con NavMesh: patrulla, persecución y ataque
- Sistema de llaves, salida, victoria y derrota
- Interfaz: menú principal, contador, mensajes y pantalla final
- Audio: música, ambiente y efectos de sonido
- Efectos visuales: partículas, pantalla roja al recibir daño y sacudida de cámara
- Optimización: Object Pooling del efecto de partículas
